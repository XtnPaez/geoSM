geoSM Lab

Arquitectura

QGIS y PostGIS locales; GeoJSON y estadísticas separadas; HTML, CSS, JavaScript, Bootstrap y Leaflet; Git y GitHub Pages.

Metodología inicial

Los códigos de localidad se asignaron mediante cruce espacial con puntos BAHRA, según el responsable del proyecto. No implica que los polígonos sean oficiales de BAHRA.

Dos localidades sin código; no se imputan valores. Fuentes geométricas, licencias y superficies pendientes de validación.
